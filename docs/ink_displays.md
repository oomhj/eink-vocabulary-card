# 墨水屏型号与硬件信息收集

> 记录收集到的 2.13" 墨水屏型号、引脚定义、驱动信息及相关硬件要点。
> 供选型、换料、固件驱动时参考。持续补充。

## 1. 概述

- 本项目（2.13 墨水屏单词卡）所用显示为 **2.13" 黑白（B/W）电子纸**，驱动 IC 为 **SSD1680（含 Z 变体）**。
- 分辨率 250×122，SPI 4 线接口，FPC 0.5mm **24P**。
- SSD1680/SSD1680Z 是这一尺寸最通用的驱动：GDEY0213B74（**SSD1680Z**）、HINK-E0266A15-A0 等同族，**固件层驱动通用**；SSD1675B 则**不通用**（见 §8/§9）。
- ⚠️ **已购实物 HINK-E0213A04-G01 是 IL3895（GDE0213B1 类）**，与前两者**都不通用**，且实测对比度浅（见 §10）。选型时优先确认驱动 IC。

## 3. GDEY0213B74（GoodDisplay）

> 驱动 IC：**SSD1680Z**（SSD1680 变体，命令集兼容）。

24-pin 引脚定义（厂商手册）：

| Pin | Name | I/O | Description |
|---|---|---|---|
| 1 | NC | – | 不接（Keep Open） |
| 2 | GDR | O | N-Channel MOSFET Gate Drive Control |
| 3 | RESE | I | Current Sense Input for the Control Loop |
| 4 | NC | – | 不接（Keep Open） |
| 5 | VSH2 | C | Positive Source driving voltage (Red) |
| 6 | TSCL | O | I2C 数字温度传感器时钟（温度传感器用） |
| 7 | TSDA | I/O | I2C 数字温度传感器数据 |
| 8 | BS1 | I | 总线接口选择（SPI/I2C） |
| 9 | BUSY | O | Busy 状态输出 |
| 10 | RES# | I | 复位，低有效 |
| 11 | D/C# | I | 数据/命令控制 |
| 12 | CS# | I | 片选 |
| 13 | SCL | I | SPI 时钟 |
| 14 | SDA | I/O | SPI 数据 |
| 15 | VDDIO | P | 接口逻辑电源，应接 VCI |
| 16 | VCI | P | 芯片电源 |
| 17 | VSS | P | 地 |
| 18 | VDD | C | 核心逻辑电源（可由 VCI 内部稳压），VDD–VSS 需接电容 |
| 19 | VPP | P | 仅供测试 |
| 20 | VSH1 | C | 正源极驱动电压 |
| 21 | VGH | C | 正栅极驱动电压 + VSH1 |
| 22 | VSL | C | 负源极驱动电压 |
| 23 | VGL | C | 负栅极驱动电压 + VCOM + VSL |
| 24 | VCOM | C | VCOM 驱动电压 |

要点：
- **VGH/VGL/VSL/VCOM（21–24）由 SSD1680 内部电荷泵产生**，外部只需按手册接电容，无需外部升压。
- VDDIO(15) 与 VCI(16) 需供电，VDD(18) 需去耦电容。
- BS1(8) 接高/低选择 SPI 模式。

| 屏脚 | 信号 | 说明 |

| 24 | VCOM | 驱动电压/电荷泵电容 |
| 23 | **VGL** | **L1(68µH)+Q9(SI2302) 外部升压供电**（预电荷泵节点） |
| 22 | VSL | 负源极电压/电容 |
| 21 | **VGH** | **L1(68µH)+Q9(SI2302) 外部升压供电**（预电荷泵节点） |
| 20 | VSH1 | 正源极电压/电容 |
| 19 | VPP | 仅供测试 |
| 18 | VDD | 核心逻辑电源（C3 1µF 去耦） |
| 17 | GND | 地 |
| 16 | VCC(VCI) | 芯片电源（接 VCC_3V3） |
| 15 | VCC(VDDIO) | 接口逻辑电源（C1 0.1µF 去耦） |
| 14 | SDA | SPI 数据 → IO13 |
| 13 | SCK | SPI 时钟 → IO14 |
| 12 | CS | 片选 → IO15 |
| 11 | DC | 数据/命令 → IO5 |
| 10 | RST | 复位 → IO2 |
| 9 | BUSY | Busy → IO4 |
| 8 | BS | 总线接口选择 |
| 7 | TSDA | 温度传感器数据 |
| 6 | TSCL | 温度传感器时钟 |
| 5 | **VSH2** | 正源极电压，**电容接地** |
| 4 | **NC** | 不接 |
| 3 | RESE | 电流检测 |
| 2 | GDR | 栅极驱动控制 |

要点：
- **外部升压（L1+Q9）供 21/23（VGH/VGL 预电荷泵节点）**——与各类 2.13" 板子的"PreVGH 21 / PreVGL 23"标准做法一致；最终电压由 IC 内部电荷泵产生。
- 4 脚 NC、5 脚 VSH2 电容接地——与 GDEY0213B74 布局完全一致，**两屏物理引脚可互换**。

## 5. 对比与兼容性

| 项 | GDEY0213B74 | HINK-E0266A15-A0（原理图） | 结论 |
|---|---|---|---|
| 逻辑/SPI（1–3, 6–14） | 同名同号 | 同名同号 | **完全一致** |
| 电源（15–18） | VDDIO/VCI/VSS/VDD | VCC/VCC/GND/VDD | ≈ 对应（VCC≈VDDIO/VCI） |
| 引脚 4/5 | NC / VSH2 | NC / VSH2 | **一致** |
| VGH/VGL（21/23） | 同脚位 | 同脚位，**由 L1+Q9 外部升压供电** | 脚位一致，供电来源不同 |

- 两屏 **物理 24P 引脚布局完全一致，可互换**。
- 差异在**驱动 IC 与供电方式**：GDEY0213B74 = SSD1680（内部电荷泵自给）；本板 HINK = SSD1675B（需要外部升压喂 21/23 预电荷泵节点）。
- 换用 GDEY0213B74 时：接口可直接用；但本板 **L1+Q9 升压输出（21/23）对 SSD1680 非必需**，建议核对是否断开/悬空，避免外部高压灌入内部电荷泵节点。
- 固件：SSD1680 与 SSD1675B 命令集不同，需用对应 GxEPD2 类（见 §6）。

## 6. 驱动与接线

- 4 线 SPI；本板接线（ESP8266 硬件 SPI）：SCLK=IO14，MOSI=IO13；CS=IO15、DC=IO5、RST=IO2、BUSY=IO4。
- 横屏：`setRotation(3)`，视口 250×122。

### GxEPD2 类 ↔ 驱动 IC 映射（已从 GxEPD2 库源码确认）

| GxEPD2 类 | 面板 | 驱动IC |
|---|---|---|
| `GxEPD2_213_B73` | GDEH0213B73 | **SSD1675B** |
| `GxEPD2_213_B74` | GDEM0213B74 | **SSD1680** |
| `GxEPD2_213_BN` | DEPG0213BN | SSD1680 |

> ⚠️ **关键**：参考固件用的 `GxEPD2_213_B73` 对应的是 **SSD1675B**（GDEH0213B73），不是 SSD1680！
> 佐证链：
> 1. **T5 实物屏丝印 = HINK-E0213A22-A0**，被 `GxEPD2_213_B73`（SSD1675B）驱动正常 → 该 HINK-E02xxx 屏是 SSD1675B；
> 2. 本板原理图屏 **HINK-E0266A15-A0 与它同族**（HINK-E02xxx）；
> 3. 本板 **外部 VGH/VGL 升压（L1+Q9）是 SSD1675B 面板的典型特征**（SSD1680 内部电荷泵）。
>
> → **HINK-E0266A15-A0 基本可判定为 SSD1675B**，原理图 "SSD1680" 标注有误。
> 新固件 GxEPD2 类：直接用参考固件的 `GxEPD2_213_B73`（SSD1675B）。

- 收集的 SSD1675B 屏（DEPG0213RHS75AF1CP 等）GxEPD2 类大概率也是 `GxEPD2_213_B73` 族（待确认）。⚠️ **HINK-E0213A30-A0 已确认是 SSD1675A、分辨率 212×104**（见 §8），非 SSD1675B 族，勿套用 B73。

### SSD1675B 主控信息（GxEPD2_213_B73 驱动源码）

**规格（`GxEPD2_213_B73.h`）**：
- WIDTH=128 / WIDTH_VISIBLE=122 / HEIGHT=250
- 支持局部刷新（`hasPartialUpdate` / `hasFastPartialUpdate` = true）
- 时序：`power_on_time`=100ms、`power_off_time`=250ms、全刷=4000ms、快刷=200ms

**初始化序列（`_InitDisplay()`，SSD1675B 命令集）**：

| 命令 | 含义 | 参数 |
|---|---|---|
| 0x74 | 模拟块控制 | 0x54 |
| 0x7E | 数字块控制 | 0x3B |
| 0x01 | Driver 输出控制 | 0xF9, 0x00, 0x00 |
| 0x3C | 边框波形 | 0x03 |
| 0x2C | VCOM 电压 | 0x50 |
| 0x03 | **栅极驱动电压** | 0x15 = **19V** |
| 0x04 | **源极驱动电压** | 0x41(VSH1 **15V**) / 0xA8(VSH2 5V) / 0x32(VSL **-15V**) |
| 0x3A | Dummy line | 0x2C |
| 0x3B | Gate time | 0x0B |

要点：
- SSD1675B 靠 **LUT（查找表）** 定义驱动波形（0x32 写 LUT，全刷/快刷各一套）——与 SSD1680 的命令式刷新不同。
- **栅极 19V / 源极 ±15V** → 面板需要外部升压产生 VGH/VGL，这正是本板 **L1+Q9 升压**的用途。
- 主控资料（GD 官方）：`downloadsId=820`（SSD1675B 数据手册）。

## 7. 相关硬件要点（本板）

- **连接器**：P1 = FPC 0.5mm 24P 翻盖座（H2.0，C11092）；MSP1 = 显示屏符号（HINK 面板），两符号同脚位。
- **屏升压**：VGH/VGL 由 **L1(68µH)+Q9(SI2302)** 升压产生（Q1 已从原理图移除）。
- **温度传感器**：TSCL/TSDA（pin 6/7）在本板未接（温度传感器为可选功能，SSD1680 驱动用不到）。
- 更多本板硬件细节见 [`hardware.md`](hardware.md)。

## 10. HINK-E0213A04-G01（IL3895）— 已购买实物，实测确认

> **驱动 IC = IL3895**（对应 GxEPD2 类 `GxEPD2_213`，面板 GDE0213B1）。
> ⚠️ **修正**：此前按 HINK 家族推断为 SSD1675B，实测否掉——这块实物屏 B73(SSD1675B)/B74(SSD1680) 驱动**均不显示**。

### 实测驱动识别（2026-08 实物，接 ESP8266 板）

| 驱动类 | 全刷 BUSY 时长 | 现象 |
|---|---|---|
| `GxEPD2_213_B73`（SSD1675B） | ~188ms（异常短） | 无显示 |
| `GxEPD2_213_B74`（SSD1680） | ~106ms（异常短） | 无显示 |
| `GxEPD2_213`（**GDE0213B1 / IL3895**） | **~3.9s（正常，对应 full_refresh_time=4000ms）** | **有反应**（图形出现） |

- 判定依据：全刷 BUSY 高电平时长与驱动 `full_refresh_time` 一致 → 屏控制器是 IL3895 命令集。
- 接线（实测）：SDA=IO13、CLK=IO14、CS=IO15、RST=IO2、BUSY=IO4、DC=IO5。

### 显示问题已澄清（2026-08 实测）

- 曾出现"图形偏淡 + 残影"，排查后**不是屏退化**：全黑/全白实测反差大、效果正常。
- 真因有两层：
  1. **flash 直读崩溃**（ESP8266 flash 区只支持 32 位访问，单字节直读 LoadStoreError）——固件把词库/字体放 flash 后，读数据即崩 → 屏空白。已在 `src/u8g2_fonts_flash.h` 修复（`u8x8_pgm_read`→`pgm_read_byte`），并实测词库(450KB)/字体(631KB)直读 OK。
  2. **IL3895 快刷（局部刷新）波形弱**，连续快刷会积累残影——全刷干净。对策：固件**快刷为主 + 每 20 次全刷清残影**（`word_cards.cpp`），已接受该取舍。
- 万用表实测 VGH/VGL = +22/-22V（正常），非升压问题。
- **SSD1680 屏无快刷残影问题**，是全刷/快刷都理想的选型（`USE_SSD1680=1`）。
